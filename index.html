AutoDock Vina Nedir?

AutoDock Vina, protein-ligand molecular docking için geliştirilmiş modern, hızlı ve kullanıcı dostu bir yazılımdır. AutoDock 4'ün yeni nesil versiyonu olarak, önemli performans iyileştirmeleri ve basitleştirilmiş workflow sunar.

✨ AutoDock Vina

  • 2-3× daha hızlı hesaplama
  • Çok çekirdekli CPU desteği
  • Basit parametre yapısı
  • Tek komut ile çalıştırma
  • Daha iyi scoring function
  • Python entegrasyonu
  • Modern arama algoritması

📚 AutoDock 4

  • Daha yavaş (tek çekirdek)
  • Karmaşık parametre sistemi
  • İki aşamalı çalıştırma
  • Manuel grid setup
  • Eski scoring function
  • GA/LGA algoritması
  • Daha detaylı kontrol

📊 Performans Karşılaştırması

Aynı sistem üzerinde yapılan testlerde:

  • AutoDock 4: 50 run × 2.5M evaluations ≈ 45-60 dakika
  • AutoDock Vina: Exhaustiveness 8, 8 CPU core ≈ 5-10 dakika

Vina, 5-10× daha hızlı sonuç verir ve genellikle daha iyi tahminler yapar.

3.2. PDBQT Dönüşümü

Üç farklı yöntem:

Yöntem 1: MGLTools (prepare_receptor4.py)

# Temel kullanım
prepare_receptor4.py -r protein.pdb -o protein.pdbqt

# Gelişmiş: su koru, pH ayarla
prepare_receptor4.py -r protein.pdb -o protein.pdbqt \
    -A checkhydrogens \
    -U nphs_lps_waters

# Parametreler:

# -e: amino aside ekle

# Receptor hazırlama

    -i protein.pdb \
    -o protein.pdbqt \
    --pH 7.4 \
    --remove_nonstd_residues \
    --keep_nonpolar_hydrogens

# Flexible residues ile (ileri düzey)

    -i protein.pdb \

Ligand Hazırlama

Ligand hazırlama, 3D yapı oluşturma, enerji minimizasyonu ve PDBQT formatına dönüşümü içerir.

4.1. 3D Yapı Oluşturma

SMILES'den Başlama

# Open Babel ile
echo "CCO" > ethanol.smi
obabel ethanol.smi -O ethanol.sdf --gen3d

# Minimizasyon ekle
obabel ethanol.smi -O ethanol.sdf \
    --gen3d \
    --minimize \
    --ff MMFF94 \
    --steps 500

PubChem/ZINC'den İndirme

# PubChem CID ile
# https://pubchem.ncbi.nlm.nih.gov/
# Format: SDF-3D indir

# ZINC veritabanı
# https://zinc15.docking.org/
# 3D format indir

4.2. Enerji Minimizasyonu

Yapısal strain'i kaldırmak için:

# Open Babel - MMFF94
obabel ligand.sdf -O ligand_min.sdf \
    --minimize \
    --ff MMFF94 \
    --steps 500 \
    --sd  # steepest descent

# UFF force field (hızlı)
obabel ligand.sdf -O ligand_min.sdf \
    --minimize \
    --ff UFF \
    --steps 200

4.3. pH'ya Göre Protonlama

# Open Babel ile pH 7.4
obabel ligand.sdf -O ligand_pH74.sdf -p 7.4

# Alternatif: ChemAxon Marvin
# GUI: Sketch → Calculate → Protonation → pH 7.4

4.4. PDBQT Dönüşümü

Meeko - Modern ve Güvenilir

# Temel kullanım
mk_prepare_ligand.py -i ligand.sdf -o ligand.pdbqt

# Gelişmiş: torsions, pH
mk_prepare_ligand.py \
    -i ligand.mol2 \
    -o ligand.pdbqt \
    --pH 7.4 \
    --merge_these_atom_types \
    --rigid_macrocycles

# Batch processing
for file in ligands/*.sdf; do
    mk_prepare_ligand.py -i "$file" -o "${file%.sdf}.pdbqt"
done

Avantajlar:

  • En güncel PDBQT format desteği
  • Doğru torsion tree
  • Macrocycle desteği
  • Python entegrasyonu

MGLTools - Klasik Yöntem

# prepare_ligand4.py
prepare_ligand4.py -l ligand.mol2 -o ligand.pdbqt

# Torsions ayarlama
prepare_ligand4.py \
    -l ligand.mol2 \
    -o ligand.pdbqt \
    -A bonds_hydrogens \
    -U nphs_lps

# Parametreler:
# -A: aromatics, bonds, hydrogens
# -U: polar hydrogens, lone pairs
# -C: yükleri sakla
# -Z: torsions sınırla

Open Babel - Hızlı Dönüşüm

# Direkt dönüşüm (temel)
obabel ligand.sdf -O ligand.pdbqt

# Hidrojen ve yük ekle
obabel ligand.sdf -O ligand.pdbqt -h --partialcharge gasteiger

# Batch
obabel *.sdf -O output.pdbqt -m

Dikkat: Open Babel'in PDBQT çıktısı bazı durumlarda Meeko/MGLTools'tan farklı olabilir. Kritik çalışmalarda Meeko tercih edilir.

4.5. Rotatable Bonds Kontrolü

# Python ile kontrol
from rdkit import Chem
from rdkit.Chem import Descriptors

mol = Chem.MolFromMolFile('ligand.sdf')
n_rotatable = Descriptors.NumRotatableBonds(mol)
print(f"Rotatable bonds: {n_rotatable}")

# PDBQT'den kontrol
grep "^REMARK.*active torsions" ligand.pdbqt

📊 Rotatable Bond Önerileri

Torsiyon Sayısı Durum Öneri
0-7 ✅ İdeal Hızlı ve güvenilir docking
8-12 ⚠️ Orta Exhaustiveness artır (16-24)
>12 ❌ Yüksek Ligandı parçala veya constrain

4.6. Kalite Kontrolü

✓ Ligand Kontrol Listesi:

  • 3D koordinatlar mevcut
  • Enerji minimize edildi
  • Hedef pH'da protonlanmış
  • Tüm hidrojenlerin mevcut
  • Gasteiger yükleri atandı
  • Rotatable bonds ≤ 12
  • Moleküler ağırlık < 900 Da
  • PDBQT dosyası hatasız

from Bio.PDB import PDBParser
import numpy as np

# PDB dosyasından belirli kalıntıları seç
parser = PDBParser()
structure = parser.get_structure('protein', 'protein.pdb')

# Aktif bölge kalıntıları (örnek: 50-60)
coords = []
for residue in structure[0]['A'][50:61]:
    for atom in residue:
        coords.append(atom.get_coord())

# Merkez hesapla
center = np.mean(coords, axis=0)
print(f"center_x = {center[0]:.3f}")
print(f"center_y = {center[1]:.3f}")
print(f"center_z = {center[2]:.3f}")

5.3. Grid Box Boyutu

📏 Boyut Hesaplama Kuralları

Genel Kural: Ligandın en uzun boyutu + 15-20 Å

  • Küçük moleküller (MW < 300): 20×20×20 Å
  • İlaç benzeri (MW 300-500): 22×22×22 Å
  • Büyük ligandlar (MW > 500): 25×25×25 Å
  • Blind docking: 30×30×30 Å veya daha büyük
# Ligand boyutunu hesapla
from rdkit import Chem
from rdkit.Chem import AllChem

mol = Chem.MolFromPDBFile('ligand.pdb')
conf = mol.GetConformer()
positions = conf.GetPositions()

# Min/max koordinatlar
min_coords = positions.min(axis=0)
max_coords = positions.max(axis=0)
dimensions = max_coords - min_coords

# Önerilen box boyutu (her yöne +10 Å)
recommended_size = dimensions + 20
print(f"Önerilen box: {recommended_size}")

5.4. Gelişmiş Parametreler

config.txt - Tüm Parametreler

receptor = protein.pdbqt
ligand = ligand.pdbqt

center_x = 15.190
center_y = 53.903
center_z = 16.917

size_x = 22
size_y = 22
size_z = 22

# Arama parametreleri
exhaustiveness = 8      # Varsayılan: 8 (8-32 arası)
num_modes = 9           # Kaç pose döndürülsün (varsayılan: 9)
energy_range = 3        # kcal/mol (varsayılan: 3)

# CPU kullanımı
cpu = 4                 # Core sayısı (varsayılan: tümü)

# Random seed (tekrarlanabilirlik için)
seed = 12345

# Çıktı dosyası
out = docking_result.pdbqt
log = docking_log.txt
exhaustiveness

Arama kapsamlılığı. Yüksek = daha hassas ama daha yavaş.

  • 8: Standart (hızlı)
  • 16: İyi hassasiyet
  • 32: Maksimum hassasiyet
num_modes

Döndürülecek binding mode sayısı.

  • 9: Varsayılan
  • 20: Daha fazla alternatif
energy_range

En düşük enerjiden kaç kcal/mol'e kadar.

  • 3: Varsayılan
  • 5: Daha geniş aralık

5.5. Otomatik Config Oluşturma

#!/usr/bin/env python3
"""AutoDock Vina config dosyası oluşturucu"""

def create_config(receptor, ligand, center, size, output="config.txt"):
    config = f"""receptor = {receptor}
ligand = {ligand}

center_x = {center[0]:.3f}
center_y = {center[1]:.3f}
center_z = {center[2]:.3f}

size_x = {size[0]}
size_y = {size[1]}
size_z = {size[2]}

exhaustiveness = 8
num_modes = 9
"""
    
    with open(output, 'w') as f:
        f.write(config)
    print(f"Config dosyası oluşturuldu: {output}")

# Kullanım
create_config(
    receptor="protein.pdbqt",
    ligand="ligand.pdbqt",
    center=[15.19, 53.90, 16.92],
    size=[22, 22, 22]
)

6.3. Sonuçları Anlama

affinity (kcal/mol)

Tahmini serbest enerji (ΔG). Daha negatif = daha güçlü bağlanma

  • < -10: Çok güçlü
  • -7 to -10: İyi
  • -5 to -7: Orta
  • > -5: Zayıf
RMSD l.b. (lower bound)

En iyi moddan minimum RMSD

Düşük RMSD = benzer binding mode

RMSD u.b. (upper bound)

En iyi moddan maksimum RMSD

Farklı binding orientation'ı gösterir

⚠️ Önemli Notlar

  • Vina skorları görecelidir: Sadece aynı protein için karşılaştırın
  • En düşük enerji ≠ en iyi poz: Mutlaka görsel validasyon yapın
  • Clustering otomatik: Vina, benzer pozları otomatik gruplar
  • Exhaustiveness: Daha yüksek değer genellikle daha iyi sonuç verir

6.4. Batch Docking

Çoklu Ligand Docking

#!/bin/bash
# batch_docking.sh

RECEPTOR="protein.pdbqt"
CONFIG="config.txt"

for ligand in ligands/*.pdbqt; do
    name=$(basename "$ligand" .pdbqt)
    echo "Docking: $name"
    
    vina --config $CONFIG \
         --receptor $RECEPTOR \
         --ligand "$ligand" \
         --out "results/${name}_out.pdbqt" \
         --log "logs/${name}.log"
done

echo "Tüm docking işlemleri tamamlandı!"

Paralel Docking (GNU Parallel)

# GNU Parallel kurulu olmalı
# Tüm ligandları paralel dock et

ls ligands/*.pdbqt | parallel -j 4 \
    "vina --config config.txt \
          --receptor protein.pdbqt \
          --ligand {} \
          --out results/{/.}_out.pdbqt"

Batch Görselleştirme Script

#!/usr/bin/env python3
"""PyMOL ile otomatik görselleştirme"""
import pymol
from pymol import cmd

def visualize_docking(protein, docking_result, mode=1):
    cmd.load(protein, "protein")
    cmd.load(docking_result, "ligand")
    
    # Modeli seç
    cmd.split_states("ligand")
    ligand_name = f"ligand_{mode:04d}"
    
    # Stil ayarları
    cmd.hide("everything")
    cmd.show("cartoon", "protein")
    cmd.color("cyan", "protein")
    cmd.show("sticks", ligand_name)
    cmd.color("green", ligand_name)
    cmd.util.cbag(ligand_name)
    
    # H-bağları
    cmd.distance("hbonds", ligand_name, "protein", 3.5)
    cmd.set("dash_color", "yellow")
    cmd.set("dash_width", 2)
    
    # Kaydet
    cmd.png(f"docking_mode_{mode}.png", width=1920, height=1080, dpi=300, ray=1)
    print(f"Görsel kaydedildi: docking_mode_{mode}.png")

# Kullanım
visualize_docking("protein.pdb", "docking_result.pdbqt", mode=1)

7.2. Etkileşim Analizi

Yöntem 1: PyMOL ile Mesafe Ölçümü

# Hidrojen bağları (2.5-3.5 Å)
distance hbonds, (ligand and acceptors), (protein and donors), 3.5

# π-π stacking (3.5-4.5 Å)
distance pi_pi, (ligand and resn PHE+TYR+TRP+HIS), \
                (protein and resn PHE+TYR+TRP+HIS), 4.5

# Hidrofobik kontaklar (<4 Å)
select hydrophobic_protein, protein and resn ALA+VAL+LEU+ILE+MET+PHE+TRP+PRO
select hydrophobic_ligand, ligand and (elem C and not neighbor elem N+O+S)
distance hydrophobic, hydrophobic_ligand, hydrophobic_protein, 4.0

#!/usr/bin/env python3
"""Vina sonuçlarını parse et"""

def parse_vina_output(pdbqt_file):
    """PDBQT dosyasından enerjileri çıkar"""
    energies = []
    
    with open(pdbqt_file) as f:
        for line in f:
            if line.startswith("REMARK VINA RESULT:"):
                parts = line.split()
                energy = float(parts[3])
                rmsd_lb = float(parts[4])
                rmsd_ub = float(parts[5])
                energies.append({
                    'energy': energy,
                    'rmsd_lb': rmsd_lb,
                    'rmsd_ub': rmsd_ub
                })
    
    return energies

# Kullanım
results = parse_vina_output("docking_result.pdbqt")
for i, res in enumerate(results, 1):
    print(f"Mode {i}: {res['energy']:.1f} kcal/mol")

7.4. Görsel Kalite Kontrolü

✓ İyi Binding Pose:

  • Polar atomlar polar kalıntılara yakın
  • H-bağı geometrisi doğru (2.5-3.5 Å, 120-180°)
  • Hidrofobik gruplar hidrofobik ceple temas ediyor
  • Ligand binding pocket'e tam oturuyor
  • Ciddi sterik çakışma yok
  • Yüklü gruplar uygun yönelimde

✗ Şüpheli Pose:

  • Ligand pocket dışında
  • Polar gruplar buried ve exposed
  • Atom çakışmaları (< vdW yarıçapları)
  • H-bağı geometrisi kötü
  • Büyük boşluklar (unfilled pockets)
  • Mantıksız konformasyonlar

  1. En az ilk 3-5 modu görsel inceleyin

8.2. Batch Virtual Screening

#!/usr/bin/env python3
"""
Otomatik virtual screening pipeline
"""
from vina import Vina
import glob
import pandas as pd
from pathlib import Path

class VirtualScreening:
    def __init__(self, receptor, center, box_size):
        self.receptor = receptor
        self.center = center
        self.box_size = box_size
        self.results = []
        
    def screen_library(self, ligand_dir, exhaustiveness=8):
        """Ligand kütüphanesini tara"""
        
        # Vina setup
        v = Vina(sf_name='vina', cpu=0)  # Tüm CPU'lar
        v.set_receptor(self.receptor)
        v.compute_vina_maps(center=self.center, box_size=self.box_size)
        
        # Tüm ligandlar
        ligands = glob.glob(f"{ligand_dir}/*.pdbqt")
        total = len(ligands)
        
        print(f"Taranacak ligand sayısı: {total}")
        
        for i, ligand_path in enumerate(ligands, 1):
            ligand_name = Path(ligand_path).stem
            print(f"[{i}/{total}] Docking: {ligand_name}")
            
            try:
                # Docking
                v.set_ligand_from_file(ligand_path)
                v.dock(exhaustiveness=exhaustiveness, n_poses=1)
                
                # En iyi enerji
                energy = v.energies()[0][0]
                
                # Kaydet
                output_file = f"results/{ligand_name}_out.pdbqt"
                v.write_poses(output_file, n_poses=1, overwrite=True)
                
                self.results.append({
                    'ligand': ligand_name,
                    'energy': energy,
                    'output': output_file
                })
                
            except Exception as e:
                print(f"  HATA: {ligand_name} - {e}")
                continue
        
        print("Tarama tamamlandı!")
        
    def save_results(self, output_file="screening_results.csv"):
        """Sonuçları CSV'ye kaydet"""
        df = pd.DataFrame(self.results)
        df = df.sort_values('energy')
        df.to_csv(output_file, index=False)
        print(f"Sonuçlar kaydedildi: {output_file}")
        
        # Özet
        print(f"\nÖzet:")
        print(f"Toplam docking: {len(df)}")
        print(f"En iyi enerji: {df['energy'].min():.2f} kcal/mol")
        print(f"Ortalama enerji: {df['energy'].mean():.2f} kcal/mol")
        
        return df

# KULLANIM
if __name__ == "__main__":
    # Parametreler
    receptor = "protein.pdbqt"
    center = [15.19, 53.90, 16.92]
    box_size = [22, 22, 22]
    ligand_library = "ligand_library"

8.3. Paralel Processing

from concurrent.futures import ProcessPoolExecutor
from vina import Vina

def dock_single_ligand(args):
    """Tek bir ligand için docking"""
    receptor, ligand, center, box_size = args
    
    v = Vina(sf_name='vina', cpu=1)  # Her worker 1 CPU
    v.set_receptor(receptor)
    v.compute_vina_maps(center=center, box_size=box_size)
    v.set_ligand_from_file(ligand)
    v.dock(exhaustiveness=8, n_poses=1)
    
    energy = v.energies()[0][0]
    output = ligand.replace('.pdbqt', '_out.pdbqt')
    v.write_poses(output, n_poses=1, overwrite=True)
    
    return {
        'ligand': ligand,
        'energy': energy,
        'output': output
    }

# Paralel çalıştırma
receptor = "protein.pdbqt"
center = [15.19, 53.90, 16.92]
box_size = [22, 22, 22]
ligands = glob.glob("ligands/*.pdbqt")

# Worker pool oluştur (16 paralel iş)
with ProcessPoolExecutor(max_workers=16) as executor:
    args = [(receptor, lig, center, box_size) for lig in ligands]
    results = list(executor.map(dock_single_ligand, args))

# Sonuçları işle
df = pd.DataFrame(results)
df = df.sort_values('energy')
df.to_csv('parallel_results.csv', index=False)

8.4. Redocking Validation Script

#!/usr/bin/env python3
"""
Otomatik redocking validasyonu
"""
from vina import Vina
from pymol import cmd
import numpy as np

def calculate_rmsd(ref_pdb, docked_pdbqt):
    """PyMOL ile RMSD hesapla"""
    cmd.load(ref_pdb, 'reference')
    cmd.load(docked_pdbqt, 'docked')
    
    # İlk modeli al
    cmd.split_states('docked')
    
    # RMSD hesapla
    rmsd = cmd.align('docked_0001', 'reference')[0]
    
    cmd.delete('all')
    return rmsd

def redocking_validation(protein, crystal_ligand, center, box_size):
    """Redocking protokolü"""
    
    print("=== Redocking Validasyonu ===\n")
    
    # 1. Crystal ligandı hazırla (zaten PDBQT formatında olmalı)
    print("1. Crystal ligand hazırlandı")
    
    # 2. Docking yap
    print("2. Docking başlatıldı...")
    v = Vina(sf_name='vina', cpu=0)
    v.set_receptor(protein)
    v.set_ligand_from_file(crystal_ligand)
    v.compute_vina_maps(center=center, box_size=box_size)
    v.dock(exhaustiveness=16, n_poses=9)
    
    # 3. Sonuçları kaydet
    v.write_poses('redocking_result.pdbqt', n_poses=9, overwrite=True)
    energies = v.energies()
    print(f"   En iyi enerji: {energies[0][0]:.2f} kcal/mol")
    
    # 4. RMSD hesapla
    print("3. RMSD hesaplanıyor...")
    rmsd = calculate_rmsd(crystal_ligand, 'redocking_result.pdbqt')
    
    # 5. Sonuç
    print(f"\n=== SONUÇ ===")
    print(f"RMSD: {rmsd:.2f} Å")
    
    if rmsd < 2.0:
        print("✅ MÜKEMMEL - Protokol valide edildi")
    elif rmsd < 3.0:
        print("⚠️  KABUL EDİLEBİLİR - Protokol makul")
    else:
        print("❌ KABUL EDİLEMEZ - Parametreleri kontrol edin")
    
    return rmsd, energies[0][0]

# Kullanım
protein = "protein.pdbqt"
crystal_ligand = "crystal_ligand.pdbqt"
center = [15.19, 53.90, 16.92]  # Crystal ligand merkezi
box_size = [22, 22, 22]

rmsd, energy = redocking_validation(protein, crystal_ligand, center, box_size)

Best Practices & İpuçları

Güvenilir ve yayınlanabilir Vina sonuçları için öneriler.

9.1. Protokol Optimizasyonu

🎯 Grid Box

  • Ko-kristalize ligand merkezini kullan
  • Box, ligandın tüm konformasyonlarını kapsasın
  • Blind docking için daha büyük box (30×30×30)
  • PyMOL ile görsel doğrulama yap

⚙️ Parametreler

  • exhaustiveness ≥ 8 (standart)
  • Kritik çalışmalar: exhaustiveness = 16-32
  • num_modes = 9-20 (alternatif modlar için)
  • Tüm CPU core'ları kullan

🧪 Validasyon

  • Redocking RMSD < 2.0 Å zorunlu
  • Birden fazla crystal yapı ile test et
  • Known active/inactive moleküllerle
  • Cross-docking (farklı protein konformasyonları)

📊 Analiz

  • İlk 3-5 modu görsel incele
  • Etkileşimleri PLIP/Prolif ile analiz et
  • Literatürle karşılaştır
  • Consensus scoring kullan

9.2. Yaygın Hatalar

❌ Sadece En Düşük Enerji

Neden Yanlış: En düşük scoring ≠ biyolojik olarak doğru

Doğrusu: İlk 5 modu incele, etkileşimlere bak

❌ Görsel Validasyon Yok

Neden Yanlış: Skorlar yanıltıcı olabilir

Doğrusu: PyMOL'de her zaman görsel kontrol

❌ Redocking Yapmama

Neden Yanlış: Protokol güvenilirliği bilinmiyor

Doğrusu: Mutlaka bilinen yapıyla validate et

❌ Küçük Box

Neden Yanlış: Alternatif binding modları keşfedilmez

Doğrusu: Ligand + 10-15 Å marj bırak

❌ Düşük Exhaustiveness

Neden Yanlış: Yetersiz sampling, tutarsız sonuçlar

Doğrusu: Minimum 8, yayın için 16+

❌ Protonasyon İhmal

Neden Yanlış: Yanlış yükler, kötü skorlar

Doğrusu: PROPKA/H++ ile pH 7.4'te protonate et

9.3. Yayın İçin Checklist

📝 Metodoloji Bölümünde Belirtilmeli:

  • AutoDock Vina versiyonu (örn: 1.2.5)
  • PDBQT hazırlama araçları (MGLTools, Meeko, vb.)
  • Protein hazırlama detayları (su, H+, yükler)
  • Protonasyon durumu belirleme yöntemi
  • Grid box koordinatları ve boyutu
  • exhaustiveness değeri
  • Enerji minimizasyon protokolü (ligand)
  • Redocking RMSD değeri

📊 Sonuçlar Bölümünde Gösterilmeli:

  • Binding affinity (kcal/mol)
  • Alternatif binding modları
  • 2D ligand etkileşim diagramı
  • 3D PyMOL görselleri
  • H-bağları ve mesafeleri
  • Kritik amino asit etkileşimleri
  • Redocking validasyon sonuçları

📁 Supplementary Material:

  • Config dosyası (config.txt)
  • Hazırlanmış yapılar (PDBQT)
  • Docking sonuçları (tüm modlar)
  • Görselleştirme scriptleri
  • Batch processing kodları (varsa)

9.4. Troubleshooting

🔴 Problem: "Cannot find atom type"

Neden: PDBQT'de tanımsız atom tipi

Çözüm:

  • Meeko veya MGLTools ile yeniden hazırla
  • Nadir elementleri kontrol et (Si, B, vb.)
  • PDBQT dosyasını manuel düzenle

🟡 Problem: Tutarsız sonuçlar

Neden: Yetersiz sampling

Çözüm:

  • exhaustiveness artır (16-32)
  • Seed ayarla (reproducibility)
  • Birden fazla run yap

🔵 Problem: Ligand binding site dışında

Neden: Box çok büyük veya yanlış yer

Çözüm:

  • Box merkezini kontrol et
  • Box boyutunu küçült
  • Ko-kristalize ligand kullan

🟢 Problem: Çok yavaş

Neden: Büyük box veya çok torsiyon

Çözüm:

  • Box boyutunu optimize et
  • Ligand torsiyonları azalt
  • Paralel processing kullan
  • GPU versiyonu dene (AutoDock-GPU)

🏆 Altın Standart Workflow

  1. Hazırlık: PROPKA/H++ ile protonasyon optimize et
  2. Validasyon: Redocking RMSD < 2.0 Å sağla
  3. Docking: exhaustiveness ≥ 16 kullan
  4. Analiz: İlk 5 modu görsel incele
  5. Etkileşim: PLIP/Prolif ile detaylı analiz
  6. Konsensus: 2-3 farklı scoring ile doğrula
  7. Deneysel: Mümkünse biyokimyasal test yap
